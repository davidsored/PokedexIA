# Integracion de capturas en README

## Resumen

Se actualizo `README.md` para mostrar directamente las capturas reales de la home y de la vista de detalle almacenadas en `docs/screenshots/`.

## Cambios realizados

- Sustitucion del bloque provisional de ejemplo por imagenes embebidas reales.
- Limpieza del texto temporal que indicaba que las capturas aun no estaban en el repositorio.
- Ajuste del roadmap para eliminar la tarea ya completada de incorporar capturas al README.

## Archivos afectados

- `README.md`
- `package.json`
- `CHANGELOG.md`
